## 📌 Descripción

**ProyectoEstructuras** es una aplicación de consola desarrollada en **C++** para administrar préstamos, validar datos de clientes y generar su **tabla de amortización**.  
Está orientado al aprendizaje de estructuras de datos, manejo de archivos y validaciones en un caso real.

---

## ✨ Funcionalidades

- 👤 Registro de clientes con validación de cédula ecuatoriana.
- 🏦 Creación de cuenta y asociación con préstamo.
- 📊 Generación y visualización de tabla de amortización.
- 💾 Persistencia de datos en archivos `.txt`.
- 🗂️ Creación y restauración de respaldos.
- ❓ Acceso a documentación de ayuda (Doxygen).
